# Evidence bundle

A small, sanitized snapshot of the reports and release records behind this vault, so the vault can be read away from the original workspace. It contains summaries, not raw evidence.

Everything except this README is generated by `tools/make_evidence_bundle.py`. Do not edit those files here. Fix the source and regenerate. `MANIFEST.txt` lists each file with short hashes of its source and bundled copy.

## Contents

| Folder | Holds |
|---|---|
| `reports/` | `REPORT.md`, `EVIDENCE.md`, `COVERAGE.md`, `PROGRESS.md` |
| `release/` | `SHA256SUMS.txt`, `manifest.json` and `CHANGELOG.md` for the current release |
| `results/` | Clean acceptance summary, FineDining run steps, and `Wraeclast` location counts |

## Not included

Raw logs, saves, screenshots, DLLs, the zip, per-object census data, and the rest of `evidence\`. The hashes prove which release was tested. The release files themselves are not here.

## Sanitization

Steam IDs, real and test character names, a player name, user-home paths and the Steam library path are replaced with placeholders such as `<real-character-1>` and `<steam-library>`. The generator stops without writing if a forbidden pattern survives. This is a pattern check, not a guarantee. Review before sharing outside this private repository. Earlier git history of this repository is not rewritten by it.

## Expected workspace layout

The vault was written inside this local tree. Only `Knowledge/` and `patches/PoVPlus.Compat/` have GitHub remotes.

```
S:\Documents\ChatGPT\PoVPlusPlus\      workspace, not a git repository
  CLAUDE.md, AGENTS.md                 session instructions, local only
  REPORT.md, EVIDENCE.md, ...          source reports, copied into this bundle
  Knowledge\                           this repository, ave-satanas/PoVPlus.Knowledge
  patches\PoVPlus.Compat\              plugin source, ave-satanas/PoVPlus.Compat
  patches\dist\                        release zip, DLL and SHA256SUMS.txt, local only
  patches\archived\                    retired plugins and 1.0.0 package, local only
  evidence\                            raw test evidence, local only
  tools\                               test tools and probes, local only
  backups\                             local only
  .cache\, .sandbox\                   decompiled mods, builds and disposable server data, local only
```

To make the vault's relative links work, clone both repositories into that shape:

```
git clone https://github.com/ave-satanas/PoVPlus.Knowledge.git <workspace>/Knowledge
git clone https://github.com/ave-satanas/PoVPlus.Compat.git <workspace>/patches/PoVPlus.Compat
```

## Links that work only locally

| In a note | Resolves to | On GitHub or a lone clone |
|---|---|---|
| `[[wikilinks]]` | Another vault note | Works in Obsidian; GitHub shows plain text |
| `../../patches/PoVPlus.Compat/...` | Plugin source | Broken unless cloned as above |
| `../../EVIDENCE.md`, `../../COVERAGE.md` | Source reports | Broken; use `reports/` here |
| `evidence\...`, `tools\...`, `backups\...` | Workspace folders | Not available. They are identifiers, not links |
| `M1` to `M33`, `F1` to `F6`, `H1`, `H2` | Headings or entries in `EVIDENCE.md` | Available in `reports/EVIDENCE.md` |
| `%APPDATA%\...`, `G:\...`, `S:\Valheim-Modding\...` | This machine | Machine-local paths, not available elsewhere |

Records carry evidence tags. A `[runtime]` claim cites an evidence id; `reports/EVIDENCE.md` describes it, and the raw files stay local. See `SCHEMA.md`.
